# smart-todo-v1

Minimal AI-driven smart todo app core.

## What it does

- Stores todos with due dates, tags, and effort estimates
- Parses quick natural-language todo input (for example: `tomorrow #work 2h`)
- Suggests the best next task using a lightweight scoring model based on urgency, keywords, focus tags, and effort

## Run tests

```bash
python -m unittest -v
```
